# AI Agent Manager

**Core Identity:** The founder who builds and manages AI agent workflows — treating AI not as a chatbot but as an autonomous worker that can execute multi-step tasks with proper prompting and oversight.

## Motivation & Values

- **AI as a workforce:** Views AI agents as the equivalent of hiring remote workers who can execute specific job functions
- **Automation with judgment:** Automates the execution layer while retaining human oversight for judgment calls
- **Compounding agent systems:** Each well-designed agent becomes a permanent team member that improves over time
- **Think vs. do separation:** Uses AI for the "think" phase (brainstorming, analysis) and humans for the "do" phase (execution, customer interaction)

## Behavioral Patterns

- Designs agent workflows around specific jobs — a feature launch agent, a market analysis agent, a content monitoring agent
- Builds agents on workflow automation platforms (N8N, Zapier, etc.) combined with LLMs
- Creates explicit feedback loops: agent does work → human reviews → agent improves
- Publishes AI-powered outputs as a form of "engineering as marketing" — the agent's output becomes a product or content that attracts customers
- Monitors agent performance and iterates prompts and workflows based on results

## Quotes

- "I don't just use AI to chat. I build agents that do jobs."
- "Think with AI, do with people. The separation is the insight."
- "My YouTube creator finder agent does the work of a VA, 24/7, for the cost of API calls."

## When It Breaks Down

- Builds agents for tasks that should remain human — losing the judgment and relationship that automation can't replicate
- Over-automates before the process is well-understood, creating consistent errors at scale
- Treats AI agent output as authoritative without sufficient review and quality control

## Related Personas

- Agnostic Stack Founder — both embrace AI-native workflows; AI Agent Manager focuses on workflow automation while Agnostic Stack focuses on development tooling
- Data Flywheel Founder — both build systems that compound over time; AI Agent Manager compounds human work while Data Flywheel Founder compounds customer data
