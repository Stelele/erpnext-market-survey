# Community Listener

**Persona archetype:** The founder who discovers paid pain by immersion in communities where target customers already gather — forums, Slack workspaces, Reddit threads, Discord servers. Pain is found, not invented.

## Lighthouse Quote

> "Your SaaS idea is probably not unique. That's fine — execution and distribution are what matter." — Rob Walling

> "Hang out in communities where your target customer complains (Reddit, Hacker News, niche forums) — look for the same problem mentioned repeatedly with emotional weight." — Rob Walling, 7 Proven Ways

## Discovery Triggers

- Repeated emotional complaints in niche communities (same problem mentioned 3+ times with frustration)
- Customers stitching together multiple tools with Zapier/integrations — workarounds reveal gaps
- Freelance developers building the same custom thing for clients repeatedly
- Reddit threads where people ask "Is there a tool that does X?" with no good answer
- Slack/Discord communities where members vent about the same workflow friction weekly
- Job postings revealing operational gaps (e.g., companies hiring for roles that software should automate)

## Validation Threshold

- 10+ distinct people in communities expressing the same pain with emotional weight
- Evidence that people have attempted workarounds (spreadsheets, manual processes, cobbled-together tools)
- Competitors exist but have poor reviews or are missing features the community wants
- Willingness to pay implied by existing spend on inadequate alternatives

## Red Flags

- Problem only mentioned once or in passing — not a recurring theme
- People complain but have never tried to solve it (implies low urgency)
- Problem is so niche the TAM is obviously too small to sustain a SaaS
- The community is transient (e.g., a temporary Reddit thread, not an ongoing forum)
- Pain is hypothetical, not experienced (people saying "it would be nice" rather than "this costs me hours every week")

## ERPNext Ecosystem Lens

ERPNext serves SMEs and mid-market companies — these companies are heavy users of niche forums, industry Slack communities, and ERP-specific forums (Frappe Forum, ERPNext community). Community Listener founders in this ecosystem would:

- Monitor ERPNext community forums for plugins/functionalities users request repeatedly
- Track ERPNext partner discussions for recurring implementation pain points
- Identify ERPNext users stitching it together with other tools (Zapier, custom scripts) — these workarounds signal gaps
- Look at ERPNext GitHub issues and feature requests with most +1s (votes = pain)
- Find ERPNext agencies that build the same customizations for multiple clients — productize those
- Monitor Reddit's r/ERPNext, r/SaaS, r/smallbusiness for ERP-related complaints

**High-value ERPNext discovery areas:**
- ERPNext implementation partners complaining about migration challenges
- Users asking for better reporting/BI integrations
- Frappe Framework developers seeking better API management tools
- ERPNext users requesting industry-specific modules (legal, healthcare, non-profit)
- Companies struggling with ERPNext's multi-company consolidation features
